## 🍃 叶子问题详解

### 🍂 叶子发黄

**【症状识别】**
- 老叶先黄 → 可能是缺氮或自然老化
- 新叶先黄 → 可能是缺铁或土壤碱化
- 叶脉绿、叶肉黄 → 典型的缺铁症状
- 叶尖先黄 → 浇水不当或肥害

**【智能诊断】**
```
问：你的植物是什么类型？
├─ 观叶植物（绿萝/吊兰/龟背竹等）
│   └─ 大概率：缺氮 → 建议施用氮肥
├─ 开花植物（月季/茉莉/栀子等）
│   └─ 大概率：缺铁 → 建议施用硫酸亚铁
└─ 多肉植物
    └─ 大概率：浇水过多 → 建议控水通风
```

**【植愈解决方案】**
1. **立即检查**：用手指插入土壤2-3cm，感受湿度
2. **对症处理**：
   - 土壤湿+黄叶 → 停水通风，检查根系
   - 土壤干+黄叶 → 浇透水，补充氮肥
   - 新叶黄+叶脉绿 → 补充铁肥（螯合铁）
3. **预防措施**：定期施肥，使用植愈推荐的肥料配方

**【恢复周期】**
- 轻度：1-2周恢复
- 中度：3-4周恢复
- 重度：需修剪病叶，2-3个月恢复

### 🥀 叶子枯萎

**【症状识别】**
- 叶片下垂变软 → 严重缺水
- 叶片干枯萎蔫 → 烂根或高温灼伤
- 叶缘焦枯 → 肥害或强光

**【紧急处理】**

| 情况 | 判断方法 | 急救措施 |
|-----|---------|---------|
| 缺水枯萎 | 土壤很干，盆很轻 | 浸盆法补水，移至阴凉处 |
| 烂根枯萎 | 土壤湿，有异味 | 立即脱盆修根，换土重栽 |
| 肥害枯萎 | 近期施过肥 | 大量清水冲洗土壤 |
| 热伤枯萎 | 夏季高温后 | 遮阴+喷雾降温 |

**【植愈提醒】** ⚠️ 烂根导致的枯萎必须在24小时内处理，否则植物可能死亡！

### 🐛 叶子被虫咬

**【虫害类型识别】**

| 虫咬特征 | 害虫类型 | 危害程度 |
|---------|---------|---------|
| 叶片缺刻、孔洞 | 青虫/毛毛虫 | ⭐⭐⭐ |
| 叶片卷曲、变形 | 蚜虫 | ⭐⭐ |
| 叶片有黄白点 | 红蜘蛛 | ⭐⭐⭐ |
| 叶片有蜜露、粘手 | 蚜虫/粉虱 | ⭐⭐ |
| 茎叶有白色棉絮 | 介壳虫 | ⭐⭐⭐ |

**【植愈绿色防治方案】**

**方案A：物理防治（推荐优先尝试）**
- 用手摘除可见害虫
- 用湿布擦拭叶片（针对蚜虫、介壳虫）
- 黄色粘虫板诱杀（针对小飞虫）
- 强力水流冲洗（针对红蜘蛛）

**方案B：生物防治**
- 苦参碱稀释500倍喷雾
- 印楝素稀释1000倍喷雾
- 肥皂水（1g肥皂:1L水）喷雾

**方案C：化学防治（严重时使用）**
- 吡虫啉3000倍（蚜虫、粉虱）
- 阿维菌素1500倍（红蜘蛛）
- 噻嗪酮2000倍（介壳虫）

### 🦠 叶子长斑

**【病害识别图谱】**

#### 褐色斑点
- **特征**：圆形或不规则褐斑，边缘深色
- **诊断**：炭疽病
- **治疗**：
  1. 摘除病叶（不要扔在花盆里）
  2. 咪鲜胺1500倍喷雾
  3. 改善通风

#### 白色粉状物
- **特征**：叶片正面白色粉层，可擦掉
- **诊断**：白粉病
- **治疗**：
  1. 硫磺悬浮剂500倍
  2. 小苏打水（5g:1L）喷雾
  3. 增加光照

#### 灰色霉层
- **特征**：灰色绒毛状，潮湿环境多发
- **诊断**：灰霉病
- **治疗**：
  1. 嘧霉胺1000倍
  2. 降低湿度
  3. 避免叶面喷水

#### 黑色小点
- **特征**：叶片有黑色小点，周围黄化
- **诊断**：黑斑病
- **治疗**：
  1. 代森锰锌600倍
  2. 清除落叶

## 🌱 生长问题

### 📉 生长缓慢

**【原因排查清单】**

- [ ] 光照是否充足？
  - 观叶植物：需要散射光
  - 开花植物：需要充足阳光
  - 多肉植物：需要直射光

- [ ] 是否该换盆了？
  - 根系从排水孔长出
  - 浇水后很快干
  - 植株生长停滞

- [ ] 是否缺肥？
  - 叶片薄而小
  - 叶色淡绿
  - 新芽少

- [ ] 温度是否适宜？
  - 多数植物：15-25℃最适宜
  - 低于10℃生长缓慢
  - 高于35℃生长停滞

**【植愈促生长方案】**
1. 检查根系，必要时换盆
2. 施用均衡肥（20-20-20）
3. 调整光照位置
4. 保持适宜温度

---

### 🌿 徒长（长得细长）

**【症状】** 茎节拉长，叶片稀疏，植株瘦弱

**【原因】** 光照不足

**【解决方案】**
1. **立即**：移至光照充足处
2. **修剪**：剪去过长枝条，促进分枝
3. **控水**：适当控水，抑制徒长
4. **补光**：使用植物补光灯（可选）

## 💧 浇水相关症状

### 浇水过多的症状
- 叶片发黄、脱落
- 茎基部发黑
- 土壤长期潮湿
- 有霉味

**【急救】** 停水→脱盆→晾干→减少浇水频率

### 浇水过少的症状
- 叶片萎蔫下垂
- 叶尖干枯
- 土壤干裂
- 植株整体干瘪

**【急救】** 浸盆补水→移至阴凉处恢复→调整浇水频率

---

## 🌡️ 环境应激症状

### 低温伤害
- 叶片水渍状斑点
- 叶片变黑、脱落
- 茎部变软

**【预防】** 冬季移至室内，保持10℃以上

### 高温伤害
- 叶片焦枯
- 叶缘卷曲
- 生长停滞

**【预防】** 夏季遮阴，增加通风，适当喷雾

### 干燥伤害
- 叶尖干枯
- 叶片边缘焦枯
- 红蜘蛛爆发

**【预防】** 增加空气湿度，定期喷雾，使用加湿器
