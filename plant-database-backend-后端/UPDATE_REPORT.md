## 📝 更新策略

### 1. 基于科属的差异化养护

根据植物所属科属，提供针对性的养护建议：

| 科属 | 光照特点 | 浇水原则 | 湿度要求 | 特殊提示 |
|------|----------|----------|----------|----------|
| 天南星科 (绿萝、龟背竹) | 明亮散射光，忌强光 | 喜湿润但怕积水 | 60%-80% 高湿度 | 汁液有毒，修剪戴手套 |
| 天门冬科 (虎皮兰、吊兰) | 耐阴也耐阳，适应性强 | 宁干勿湿，极耐旱 | 40%-60% 即可 | 冬季保持土壤偏干 |
| 桑科 (琴叶榕、橡皮树) | 明亮散射光，耐半阴 | 宁干勿湿，忌积水 | 50%-70% 湿润 | 最怕积水烂根 |
| 五加科 (鹅掌柴) | 明亮散射光，忌暴晒 | 喜湿润，保持土壤湿润 | 60%-80% 高湿度 | 高湿度是关键 |
| 竹芋科 (竹芋、肖竹芋) | 半阴环境，忌强光 | 喜湿润，用软水 | 70%-80% 极高湿度 | 对水质敏感，叶缘易焦枯 |

### 2. 基于类别的特殊护理

| 类别 | 养护重点 | 特殊提示 |
|------|----------|----------|
| 观叶植物 (foliage) | 叶片清洁、氮肥为主 | 定期擦拭叶片保持光泽 |
| 多肉植物 (succulent) | 宁干勿湿、充足光照 | 夏季遮阴通风，防止徒长 |
| 观花植物 (flowering) | 花期前增施磷钾肥 | 花后及时剪去残花 |
| 蕨类植物 (fern) | 高湿度、避免直射 | 干燥季节经常喷雾 |
| 仙人掌 (cactus) | 极耐旱、充足阳光 | 冬季可断水 |
| 爬藤植物 (climbing) | 提供支架、定期修剪 | 可垂吊或攀援造型 |
| 香草植物 (herb) | 充足光照、经常采摘 | 采收前 2-3 天停止施肥 |
| 水培植物 (aquatic) | 每周换水、清洗根系 | 添加少量水培营养液 |

### 3. 原产地气候适配

根据植物原产地提供温度建议：
- **热带**: 冬季需保暖（不低于 15°C），喜高湿度
- **亚热带**: 较耐寒（不低于 8°C），适应性强
- **温带**: 耐寒性好，可耐受短期 5°C 低温
- **沙漠**: 耐高温，极耐干燥
- **地中海**: 喜温暖干燥，夏季注意通风

## 📋 更新内容示例

### 绿萝 (天南星科)
**养护贴士**:
- 💧 天南星科植物汁液有毒，修剪时戴手套，避免接触皮肤和误食
- 🧹 定期用湿软布擦拭叶片，保持光泽和光合作用效率
- 🪴 气生根发达的品种可引导其攀附支架或垂吊生长
- 💨 保持通风可预防红蜘蛛和介壳虫

### 虎皮兰 (天门冬科)
**养护贴士**:
- 💧 浇水前务必确认土壤完全干燥，可用竹签插入土中检查
- 🌡️ 冬季保持土壤偏干可增强抗寒能力
- 🪴 浅盆种植更佳，避免深盆积水烂根
- ⚠️ 部分品种叶片汁液有毒，避免儿童和宠物误食

### 竹芋 (竹芋科)
**养护贴士**:
- 💧 竹芋对水质敏感，最好用晾晒过的自来水或雨水
- 💨 湿度是关键，干燥环境叶缘会焦枯卷曲
- 🌡️ 冬季注意保暖，低于 15°C 易受冻害
- 🌙 部分品种叶片夜间会闭合，属正常现象

## 🔧 技术实现

使用 `enrich-with-knowledge.py` 脚本，基于植物学知识库智能生成养护内容：

```bash
cd /mnt/d/软件/植物/plant-database-backend
python3 enrich-with-knowledge.py
```

### 知识库结构
- `FAMILY_CARE_PROFILES`: 按科分类的养护特征（5 个主要科属）
- `CATEGORY_PROFILES`: 按类别的养护重点（8 个类别）
- `ORIGIN_PROFILES`: 原产地气候特征（5 种气候类型）

### 生成逻辑
1. 根据植物科属匹配养护特征
2. 根据类别添加特殊护理提示
3. 根据原产地调整温度/湿度建议
4. 组合生成个性化的养护指南和贴士
